# MiMo Agent Toolkit

An AI-driven developer toolkit built on multi-agent collaboration architecture. Powered by Xiaomi MiMo.

## Overview

MiMo Agent Toolkit is a multi-agent system designed to automate common developer workflows. It solves the core pain point of developers frequently switching between multiple tools and websites for format conversion, encoding/decoding, regex testing, and environment setup.

## Architecture

The system uses a **multi-agent collaboration** architecture with long-chain reasoning:

```
User Input
    │
    ▼
┌──────────────┐
│ Intent Parser │ ── Identifies user needs, matches best agent
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  WebSearch +  │ ── Retrieves latest docs & solutions
│   WebFetch    │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│   Executor   │ ── Runs commands, generates code, operates files
└──────┬───────┘
       │
       ▼
┌──────────────┐
│   Reviewer   │ ── Validates results, ensures accuracy
└──────┬───────┘
       │
       ▼
  Output to User
```

## Core Features

- **Intent Parsing**: Automatically identifies user requirements
- **Information Retrieval**: Real-time search and document fetching
- **Automated Execution**: Environment setup, code generation, file operations
- **Quality Review**: Result validation and error correction
- **Long-chain Reasoning**: Handles complex multi-step tasks end-to-end

## Tech Stack

- **AI Model**: Xiaomi MiMo (V2.5)
- **Runtime**: Node.js v24.14.1
- **Agent Framework**: WorkBuddy Agent Platform
- **Tools Integration**: WebSearch, WebFetch, Bash, File I/O

## Example Usage

```bash
# Environment auto-setup example
$ agent setup "Install GitHub Copilot CLI"
→ Checking Node.js version... ✓ v24.14.1
→ Searching official docs... ✓ Found
→ Running: npm install -g @github/copilot
→ Verifying: copilot --version → 1.0.38
→ Done! GitHub Copilot CLI installed successfully.

# JSON formatting example
$ agent tool json-format '{"name":"test","value":123}'
{
  "name": "test",
  "value": 123
}
```
